# 🚧 RoadSage – Road Damage Reporting and Monitoring System

RoadSage is a web-based application designed to report, detect, and monitor road damage using GPS location tracking and AI-powered image analysis. It enables citizens to report damaged roads by uploading images and location details, while administrators monitor reports, prioritize critical damage, and track repair progress.

## ✨ Features

- 📸 **Road Damage Reporting** – Upload images of damaged roads in JPG format.
- 📍 **GPS Location Tracking** – Capture the current location of reported road damage.
- 🤖 **AI-Based Detection** – Analyze road damage images and classify severity as Low, Medium, or Critical.
- 🖥️ **Admin Dashboard** – Monitor and manage road damage reports from a centralized control room.
- 🚨 **Priority Management** – Identify critical damage and prioritize urgent action.
- 📊 **Status Tracking** – Track reports as Pending, In Progress, or Completed.
- 🗂️ **Image Management** – Organize uploaded road damage images for review and monitoring.

## 🚀 Getting Started

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone <your-repository-url>
   ```

2. Navigate to the project directory:

   ```bash
   cd <project-folder>
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the application:

   ```bash
   npm start
   ```

5. Open the local URL displayed in your terminal.

## 🔄 Workflow

1. A user captures and uploads a road damage image.
2. The application captures the GPS location of the damaged road.
3. AI analyzes the image and estimates the damage severity.
4. The report appears on the admin dashboard.
5. The control room reviews the report and prioritizes critical cases.
6. Authorities take action and update the repair status.
7. The report is tracked until the repair is completed.

## 🎯 Project Objective

RoadSage aims to improve road safety and maintenance by simplifying damage reporting, enabling location-based monitoring, supporting AI-assisted severity assessment, and helping authorities prioritize repairs efficiently.
